# 界面规范

桌面端（M3c）和 iOS 的视觉规则，两端保持一致。实现：桌面端 desktop/frontend/src/theme.ts（颜色、圆角）和 src/icons.ts（图标）；iOS 是 ios/Portide/Core/Theme.swift 和 Icons.swift；应用图标由 desktop/build/gen-icons.go 绘制。

## 颜色

| 令牌 | 用途 | 浅色 | 深色 |
|---|---|---|---|
| `bg` | 窗口底色、收到的气泡、卡片 | `#FFFFFF` | `#161922` |
| `rail` | 图标栏 | `#F3F4F8` | `#0F1117` |
| `list` | 列表栏 | `#F8F9FC` | `#12151C` |
| `feed` | 内容区（消息流）底色 | `#FBFCFE` | `#0D0F14` |
| `fg` | 正文 | `#111827` | `#F3F4F6` |
| `fg2` | 次一级正文 | `#374151` | `#D1D5DB` |
| `muted` | 次要文字、图标 | `#6B7280` | `#9CA3AF` |
| `line` | 分割线、边框 | `#E8EAF0` | `#262A35` |
| `chip` | 浅灰块：搜索框、工具按钮、日期分隔 | `#EEF0F5` | `#1E222C` |
| `accent` | 强调：选中、链接、发出的气泡 | `#4F46E5` | `#6366F1` |
| `accentSoft` | 强调浅底：拖放高亮、选中的分段按钮 | `#EEF0FF` | `#1E1B4B` |
| `ok` / `okSoft` | 成功、在线 | `#16A34A` / `#DCFCE7` | `#22C55E` / `#052E16` |
| `warn` / `warnSoft` | 警告、排队 | `#D97706` / `#FEF3C7` | `#F59E0B` / `#3A2A05` |
| `err` / `errSoft` | 错误、失败、危险操作 | `#DC2626` / `#FEE2E2` | `#F87171` / `#3B0D0D` |

- 主按钮和应用图标用渐变 `#6366F1 → #4F46E5`（135°），文字白色。
- 列表里选中的一项：白底（深色 `#1E222C`）加极淡的阴影 `0 1px 3px rgb(17 24 39 / 0.08)`。
- 提示条分三种：成功（`ok`）、警告（`warn`）、错误（`err`）。发送失败等错误一律用红色。

## 圆角、字体、尺寸

- 圆角：按钮和输入框 9px，卡片和气泡 12px，对话框 16px；头像是边长的 30%。
- 字体：系统中文字体（Linux 是 Noto Sans CJK，Windows 是微软雅黑，Apple 平台是苹方）；地址、指纹、配对码用等宽字体。
- 字号：正文 14，次要 13，说明 12，标题 16 / 18 / 22。
- 桌面端三栏：图标栏 56px，列表栏 232px，窗口最小 860×560。

## 图标

统一用 [lucide](https://lucide.dev) 线条图标，线宽 2；导航 19px，列表 16–18px。iOS 可以用对应的 SF Symbols，形状尽量接近。

### 设备类型

| 图标名 | lucide | 颜色 | 按设备名猜 |
|---|---|---|---|
| `laptop` 笔记本 | `laptop` | `#4F46E5` | 含"笔记本"、laptop、notebook、MacBook、ThinkPad |
| `tablet` 平板 | `tablet` | `#059669` | 含"平板"、iPad、tablet、pad |
| `smartphone` 手机 | `smartphone` | `#DB2777` | 含"手机"、phone、android、pixel、galaxy、redmi、huawei、honor |
| `monitor` 台式机 | `monitor` | `#0891B2` | 其余 |

按顺序判断（先认笔记本：ThinkPad 的名字里也有 pad）。用户可以在设备详情里手动换，选择只保存在本机，不同步。头像：圆角方块，底色是图标颜色的 13% 透明度；右下角圆点表示在线（`ok`）或离线（`muted`）。

### 连接方式和状态

| 含义 | lucide |

## 应用图标

A2「单条流线」（矢量稿 `site/public/assets/mark.svg`，64×64）：深色圆角方块（`#102A33`，圆角 15），两个浅色端口代表设备（`#F3F8F4`，15×18、圆角 4），中间一条薄荷绿流线代表传输（`#58E0BC`，线宽 6.5、圆头）。托盘图标相同，有正在进行的传输时右下角加一个带白边的薄荷绿点。iOS 图标是不带圆角、不透明的同一张图（圆角由系统加上）。所有尺寸由 `desktop/build/gen-icons.go` 生成；应用内的标志用桌面端的 `AppMark.tsx`、iOS 的 `AppMark.swift`，和矢量稿同一套坐标。

## 文字

- 界面只有中文。设备名、文件名用直角引号括起来：「台式机」。
- 时间：今天只显示"14:03"，昨天显示"昨天"，更早显示"10-24"；消息流按"今天 / 昨天 / 10月24日"分隔，同一台设备 5 分钟内的连续消息不重复显示时间。
- 大小按 1024 进位："2.4 MB"。
