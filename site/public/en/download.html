After installing

Three steps to your first file

  1. Name the device. Click Get started and give it a name your other devices will see.
  2. Pair a second device. Open Add device on both: Show code on one, Enter code on the other, and type the 8 digits.
  3. Send. Open that device’s conversation and drop in files, photos or text. Pair more devices the same way.

Verify your download

Every release lists a SHA-256 checksum for each file in SHA256SUMS.txt. Download it next to your file, then check:

# Linux: checks every file you downloaded
sha256sum -c --ignore-missing SHA256SUMS.txt

# macOS: compare with the file's line in SHA256SUMS.txt
shasum -a 256 portide-desktop-*.dmg

# Windows (PowerShell): the same, in capitals
Get-FileHash .\portide-desktop-*-setup.exe
SHA256SUMS.txt

Updating and removing

  • Updates: the desktop app checks GitHub once a day and shows a dot on Settings when a new version is out. Install it over the old one; your devices, history and settings stay.
  • Turn off update checks in Settings › About, or set PORTIDE_NO_UPDATE_CHECK=1 for the command line.
  • Uninstalling keeps your data folder, so reinstalling brings everything back. Delete it to remove everything: ~/Library/Application Support/portide, %APPDATA%\portide or ~/.config/portide.
