Common problems

Quick fixes

Connecting

My devices can’t find each other
  • Put both devices on the same Wi‑Fi network. Guest networks and public hotspots often stop devices from seeing each other; use a relay there.
  • Allow Local Network access. iPhone and iPad: Settings › Privacy & Security › Local Network › Portide. Mac: System Settings › Privacy & Security › Local Network.
  • On Windows, allow Portide on private networks in Windows Firewall, and make sure your Wi‑Fi is set to a private network.
  • Still nothing? In Add device, choose Can’t find the other device? and enter one of the other device’s addresses, listed under Settings › Network & relays › This device’s addresses.
The pairing code doesn’t work

A code lasts 5 minutes and stops working after a few wrong tries. Show a new code and type it on the other device while both are on the Add device screen. If the devices can’t find each other at all, see the question above.

It works at home but not when I’m away

Away from your network, devices need a relay to reach each other. Add one under Settings › Network & relays (it syncs to every device in your circle). You can run your own relay on any small Linux server.

Transfers are slow

The fastest path is direct, on the same network. Through a relay, speed depends on the relay’s connection. If the relay status reads Connected (TCP), your network is blocking UDP and transfers are slower; devices switch back on their own when UDP works again.

iPhone and iPad

My iPhone doesn’t receive in the background

iOS doesn’t let apps keep network connections open in the background. Your iPhone receives while Portide is open or just moved to the background. Anything sent meanwhile waits on the other device and arrives the next time you open Portide.

Received photos don’t show up in Photos

Saving to Photos needs permission. Check Settings › Receiving in Portide and Settings › Privacy & Security › Photos › Portide on your device. Other files are in the Files app, under On My iPhone › Portide.

Desktop

Windows says “unknown publisher”

The installer isn’t code-signed yet. Click More info › Run anyway.

Where do received files go?

To the folder under Settings › Receiving › Save to. If a file with the same name is already there, the new one is renamed; nothing is overwritten.

There’s no tray icon on Linux

Stock GNOME needs the AppIndicator extension (gnome-shell-extension-appindicator). Without a tray, closing the window quits Portide instead of leaving it running unseen.

It says the port is already in use

Another program, often a second copy of Portide or portide daemon on the same data folder, is using the port. Quit it, or choose Start on another port. Devices where you typed this computer’s address by hand then need the new one.

Devices and data

I lost a device

Remove it from your circle on any other device (Devices › the lost device › Remove from circle). That replaces the circle’s keys, so the lost device can’t connect or read anything sent afterwards.

I’m moving to a new computer or reinstalling

Uninstalling keeps your data folder, so reinstalling on the same computer brings everything back. On a new computer, install Portide and pair it with one of your devices like any other device; then remove the old computer from your circle.

Reporting a problem

These help us find it quickly:

  • Portide version: Settings › About in the apps, or portide version.
  • Devices and systems, for example “iPhone 15, iOS 26 and Windows 11”.
  • How they connect: same Wi‑Fi, or through a relay.
  • What you did, what you expected, and what happened instead. A screenshot of any error helps.
  • Never send pairing codes, relay config strings (they contain access tokens) or personal files.

Security issues

If you think you’ve found a way to read someone’s files, impersonate a device or learn more than a relay should, please report it privately instead of in a public issue. We acknowledge reports within 3 working days.
