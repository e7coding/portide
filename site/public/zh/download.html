装好之后

三步发出第一个文件

  1. 给设备起个名字。点"开始使用"，起一个你的其他设备能认出的名字。
  2. 配对第二台设备。两边都打开"添加设备"：一台点"显示配对码"，另一台点"输入配对码"，输入那 8 位数字。
  3. 发送。打开那台设备的会话，拖进文件、照片或文字。更多设备照同样方法配对。

校验下载的文件

每个版本都在 SHA256SUMS.txt 里列出每个文件的 SHA-256 校验值。把它下载到文件旁边，然后：

# Linux：一次校验下载的所有文件
sha256sum -c --ignore-missing SHA256SUMS.txt

# macOS：和 SHA256SUMS.txt 里对应那一行比对
shasum -a 256 portide-desktop-*.dmg

# Windows（PowerShell）：同样比对，结果是大写
Get-FileHash .\portide-desktop-*-setup.exe

更新和卸载

  • 更新：桌面版每天向 GitHub 查一次，有新版本时"设置"上会出现一个小圆点。直接覆盖安装，设备、历史和设置都会保留。
  • 关闭更新检查：在"设置 › 关于"里关掉；命令行设置 PORTIDE_NO_UPDATE_CHECK=1。
  • 卸载不会删除数据文件夹，重装后一切都在。想彻底清除就删掉它：~/Library/Application Support/portide、%APPDATA%\portide 或 ~/.config/portide。
